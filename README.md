# Industrial IoT Safety Monitoring System

[](https://opensource.org/licenses/MIT)
[](https://github.com/durai04d-arch/industry-oit)

An advanced IoT solution for real-time monitoring and automated safety control of industrial machinery. This system uses an ESP32 to collect data from multiple sensors, log it to a cloud database, and trigger local safety alerts and shutdowns based on pre-defined thresholds.

## 📋 Features

  * **Real-Time Data Logging:** Continuously reads sensor data and sends it to a Supabase cloud database every 5 seconds.
  * **Multi-Sensor Integration:** Monitors Temperature, Humidity, Gas Levels (MQ-6), and Proximity (Ultrasonic).
  * **Automated Safety Shutdown:** A relay module automatically cuts power to machinery if the temperature exceeds a critical threshold.
  * **Smart Alerts:** Provides both visual (LED) and audible (Buzzer) alerts for proximity breaches and high-temperature events.
  * **RFID Access Control:** Uses an MFRC522 reader to authenticate users. Authorized scans are logged and grant access to the local display.
  * **Animated OLED Display:** A local 0.96" OLED screen shows a dynamic idle animation, a personalized welcome message on successful login, and live sensor data.
  * **Cloud Backend:** Built on Supabase, utilizing a structured, multi-table PostgreSQL database for robust data storage.
  * **Remote Monitoring:** Data can be viewed and analyzed from anywhere through a web dashboard connected to the Supabase backend.

## 🏗️ System Architecture

The project's data flow is divided into a continuous monitoring loop and a user interaction loop.

1.  **Continuous Monitoring:** Sensors gather data, which is processed by the ESP32. The ESP32 triggers immediate local alerts (Relay, LED, Buzzer) and simultaneously sends the data to dedicated tables in Supabase for long-term storage and analysis.
2.  **User Interaction:** A user scans an RFID card. The ESP32 validates the card against its authorized list, logs the scan event to Supabase, and grants access to the local OLED display.

## ⚙️ Software & Cloud Setup

### 1\. Backend (Supabase)

You need a Supabase project to store the data.

1.  Create a project at [supabase.com](https://supabase.com).
2.  Go to the **SQL Editor** in your project dashboard.
3.  Run the following SQL script to create all the necessary tables:
    ```sql
    -- Table for Temperature and Humidity Sensor
    CREATE TABLE public.dht11_readings (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      created_at TIMESTAMPTZ DEFAULT NOW(),
      temperature FLOAT,
      humidity FLOAT
    );

    -- Table for Gas Sensor
    CREATE TABLE public.mq6_readings (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      created_at TIMESTAMPTZ DEFAULT NOW(),
      gas_level INT,
      unit TEXT DEFAULT 'PPM'
    );

    -- Table for Ultrasonic Sensor
    CREATE TABLE public.ultrasonic_readings (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      created_at TIMESTAMPTZ DEFAULT NOW(),
      distance_cm INT
    );

    -- Table for logging EVERY RFID scan
    CREATE TABLE public.rfid_scans (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      created_at TIMESTAMPTZ DEFAULT NOW(),
      card_uid TEXT,
      user_name TEXT,
      is_authorized BOOLEAN
    );

    -- Table for discrete system events
    CREATE TABLE public.system_events (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      created_at TIMESTAMPTZ DEFAULT NOW(),
      event_type TEXT,
      description TEXT
    );
    ```
4.  Go to **Authentication -\> Policies** and disable **Row Level Security (RLS)** for each new table to allow the ESP32 to insert data.

### 2\. Firmware (ESP32)

The firmware is written using the Arduino framework.

1.  **Setup Arduino IDE:** Make sure you have the ESP32 board manager installed.

2.  **Install Libraries:** Open the Library Manager (`Sketch > Include Library > Manage Libraries...`) and install the following:

      * `Adafruit SSD1306` (and its dependency, `Adafruit GFX Library`)
      * `MFRC522` (by GitHubCommunity)
      * `DHT sensor library` (by Adafruit)
      * `Arduino_JSON`

3.  **Configure Credentials:** In the main sketch file, update the following section with your Wi-Fi details, Supabase URL, and Supabase `anon` key.

    ```cpp
    // -- Wi-Fi & Supabase Credentials --
    const char* ssid = "YOUR_WIFI_SSID";
    const char* password = "YOUR_WIFI_PASSWORD";
    String supabaseUrl = "https://YOUR_PROJECT_ID.supabase.co";
    String supabaseKey = "YOUR_SUPABASE_ANON_KEY";
    ```

4.  **Upload:** Connect your ESP32, select the correct board and port, and upload the code.

## 🚀 Usage

1.  Power on the ESP32 via USB.
2.  The device will automatically connect to Wi-Fi and begin monitoring sensors. The OLED display will show an idle animation.
3.  Data is sent to your Supabase project every 5 seconds.
4.  If the temperature exceeds the `TEMP_THRESHOLD_CELSIUS`, the relay will de-activate (shutting down the connected machine) and the buzzer will sound a continuous alarm.
5.  If an object is detected within the `DANGER_THRESHOLD_CM`, the LED will light up and the buzzer will beep.
6.  Scan an authorized RFID card to view live data on the OLED display. The display will show a welcome animation and then the data for 10 seconds. Each scan is logged to Supabase.
